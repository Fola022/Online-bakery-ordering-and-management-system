# Online-bakery-ordering-and-management-system
Web based cake ordering and proceedings 
The Online Bakery Ordering and Management System is a web-based application designed to make bakery shopping easier and more convenient. Customers can explore available bakery products, view product details, add items to their shopping cart, and place orders online.

The system was developed using HTML, CSS, and JavaScript. It features a responsive user interface and uses browser LocalStorage to save cart items and customer orders.

Features

- Browse available bakery products.
- Search and filter products by category.
- Add products to the shopping cart.
- Increase or decrease product quantities.
- Remove items from the cart.
- Place orders through a checkout form.
- Save cart items and orders in the browser.

Technologies

HTML, CSS, JavaScript and LocalStorage.

How to Run

Open the project folder in Visual Studio Code and launch "index.html" using Live Server.
